# Lagos Prime Real Estate Web Application

A luxury real estate platform featuring modern architectural villas, waterfront penthouses, land plots, viewing appointments, real-time Firestore synchronization, and curated editorial property catalogs.

---

## 🚀 Quick Start (Run Locally in VS Code)

### Prerequisites
Make sure **[Node.js](https://nodejs.org/)** (v18 or v20+ LTS) is installed on your computer.

### Method 1: Automated 1-Click Launch (Easiest)
- **Windows**: Simply double-click `run-windows.bat`.
- **Mac / Linux**: Open Terminal and run `./run-mac-linux.sh`.

It will automatically run `npm install` and start the server at `http://localhost:3000`.

---

### Method 2: Manual VS Code Steps
1. Open **VS Code**.
2. Click **File** &rarr; **Open Folder...** and select this directory.
3. Open the integrated terminal (`Ctrl + ~`).
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open your browser and go to:
   ```text
   http://localhost:3000
   ```

---

## 🛠 Available Scripts

- `npm run dev`: Runs the development server on `http://localhost:3000`.
- `npm run build`: Builds optimized production assets in `dist/`.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Checks for TypeScript and syntax errors.
